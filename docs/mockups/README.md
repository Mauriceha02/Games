# Spieltisch-Entwürfe

`index.html` im Browser öffnen. Keine Installation nötig; die vorhandenen Kartenbilder werden lokal geladen.

- **A:** Stapel oben, kompakte Handkarten unten, ausgelegte Phasen scrollen in der Mitte. Abwerfen behält eine 44 px hohe Taste.
- **B:** Stapel und Hand gemeinsam unten.
- **C:** Ausgelegte Phasen über Spieler-Tabs wechseln; Vergleichsansicht bei Bedarf.

Karten antippen, Anlegestellen ausprobieren und den Tisch scrollen. Aktionen sind simuliert; Spielstände werden nicht gelesen oder geändert.

`vergleich.png` zeigt alle Varianten; `variante-a.png` bis `variante-c.png` zeigen sie einzeln. Die Entwürfe sind nicht Teil der veröffentlichten App.
